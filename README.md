# *PokéDex App* 
Bienvenido a la PokéDex App, una aplicación web diseñada para explorar la información del universo Pokémon. Este proyecto consume la PokeAPI oficial para ofrecer datos detallados sobre las distintas criaturas.

# Sobre la API Utilizada: PokeAPI
El núcleo de datos de esta aplicación está impulsado por PokeAPI, una interfaz de programación de aplicaciones RESTful pública que concentra la información completa de la franquicia.

# Características Principales de la API:
Base de Datos Exhaustiva: Proporciona datos sobre Pokémon, habilidades, tipos, movimientos, cadenas de evolución y estadísticas base.

# Respuesta en Formato JSON:
Datos estructurados que facilitan el procesamiento y el renderizado dinámico en la interfaz.

# Recursos Multimedia: 
Acceso a sprites oficiales, ilustraciones y variantes variocolor (shiny).

# Acceso Público:
Permite la integración mediante peticiones HTTP asíncronas sin necesidad de claves de autenticación.

# Características de la Aplicación
# Buscador Dinámico:
Permite filtrar y encontrar Pokémon por nombre o número de identificación.

# Visualización de Estadísticas Base:
Presentación clara de los valores de salud, ataque, defensa, velocidad y estadísticas especiales.

# Adaptación Visual por Tipo:
La interfaz ajusta su esquema de colores según el tipo primario del Pokémon seleccionado.

# Diseño Adaptativo:
Interfaz optimizada para su correcta visualización en dispositivos móviles y de escritorio.

# Galería de Imágenes:
Muestra de sprites e ilustraciones en alta resolución.

# Tecnologías Utilizadas
. HTML5:
Estructura semántica de la interfaz web.

 .CSS3:
 Estilos, maquetación mediante Flexbox y Grid, y diseño adaptativo.

.JavaScript (ES6+): 
Lógica de la aplicación, manipulación del DOM y consumo asíncrono de la API mediante Fetch y Async/Await.

.PokeAPI v2:
Fuente externa de datos.

.Git y GitHub: 
Control de versiones y alojamiento del código fuente.
